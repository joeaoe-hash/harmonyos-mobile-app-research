这份说明不使用某个应用的案例数据。它展示 7 个 Skill 为什么这样设计、怎样协同、证据如何流转、使用者如何发起任务，以及这套能力如何在团队内复用。

## 脱敏说明

- 示例只讲公开的方法、流程、角色和输出，不使用真实应用案例或业务指标。
- 示例不包含真实用户名、账号、设备标识、组织信息、内部结论或未公开版本计划。
- 所有页面均标注“公开演示 · 不含业务数据”。

## 这个示例重点演示

1. 从范围锁定、证据采集到结构化分析和成果交付的完整链路。
2. 7 个 Skill 的分层、职责、输入输出和选择逻辑。
3. 原始证据如何经过标准数据合同，变成可追溯的管理结论。
4. 真机、网页、已有材料和纯分析四种工作模式怎样切换。
5. 每个阶段的质量门禁、隐私边界和团队推广方式。
