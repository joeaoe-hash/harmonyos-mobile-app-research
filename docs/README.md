# 使用文档

本目录解释“鸿蒙应用解决方案助手”中的 7 个 Skill 如何协作、各自怎样运行，以及使用者应该怎样下达任务。

## 推荐阅读顺序

1. [Skill 工作原理、流程与用法](SKILL_WORKFLOWS.md)：完整了解每个 Skill 的输入、处理步骤、输出、依赖和边界。
2. [依赖与安装](../plugins/harmonyos-mobile-app-research/DEPENDENCIES.md)：按任务安装最小依赖。
3. [隐私规则](../PRIVACY.md)：公开或共享结果前的脱敏要求。
4. [工作流程与方法论](../examples/workflow-methodology/README.md)：查看不含业务数据的 Markdown 与 DOCX 成品。

如果只想马上开始，安装插件后新建一个任务，直接描述目标、应用、平台、时间范围和现有材料。插件会根据任务自动选择合适的 Skill；复杂任务会串联多个 Skill。
