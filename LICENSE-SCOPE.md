# 许可范围 / License Scope

本仓库采用混合许可，以便开放 Skill 能力，同时保留已经完成的报告成品。

This repository uses mixed licensing so that the skills can remain open source while completed report materials remain protected.

## MIT 覆盖范围 / MIT-covered materials

除下方明确列出的例外目录外，本仓库内容按照根目录 [MIT License](LICENSE) 开放，包括：

- 插件清单和市场元数据；
- 7 个 Skill 的定义、工作流说明和代理元数据；
- 脚本、提示词、数据结构、校验规则和模板；
- 合成测试样本；
- README、依赖说明、贡献指南及其他项目文档；
- 项目展示图片和仓库维护工具。

Except for the directories explicitly excluded below, repository content is licensed under the root [MIT License](LICENSE), including plugin metadata, skill definitions, workflow documentation, scripts, prompts, schemas, validators, templates, synthetic fixtures, and general project documentation.

## 不属于 MIT 的报告材料 / Report materials excluded from MIT

以下目录及其全部内容不适用根目录 MIT License：

1. `examples/workflow-methodology/**`
2. `plugins/harmonyos-mobile-app-research/skills/app-satisfaction-report/references/examples/**`

这些目录包含已经完成的报告、方法论成品、伴读版、图表和排版资产。它们仅作为 Skill 输出结构与质量效果的阅读参考，版权保留；具体条件以各目录中的 `LICENSE` 文件为准。

The directories above contain completed reports, methodology deliverables, companion editions, charts, and layout assets. They are provided only as references for understanding expected output structure and quality. They are not licensed under MIT; the `LICENSE` file inside each excluded directory controls those materials.

## 如何判断 / How to interpret the scope

- 路径位于例外目录内：适用该目录的保留版权声明。
- 其他路径：适用根目录 MIT License，除非文件自身另有明确说明。
- 对许可边界有疑问时，不要复制或再分发现成报告；请先通过 Issue 联系项目维护者。

- A path inside an excluded directory follows that directory's reserved-rights notice.
- Any other path follows the root MIT License unless the file explicitly says otherwise.
- If the boundary is unclear, do not copy or redistribute a completed report; open an Issue first.
