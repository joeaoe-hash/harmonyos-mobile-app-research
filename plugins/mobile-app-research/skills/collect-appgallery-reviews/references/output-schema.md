# 评论数据输出规范

## CSV 编码

使用 UTF-8 BOM（`utf-8-sig`），确保 Windows Excel 正确显示中文。

## 字段

| 字段 | 含义 |
|---|---|
| 序号 | 当前输出文件内从 1 开始的顺序 |
| 列表位置 | “最新”列表中的规范化索引，用于断点和缺口审计 |
| 发布时间 | ISO 日期，可附带 `HH:MM` |
| 页面显示时间 | UI 原始日期文本 |
| 评分 | 1–5；控件未实例化时可能为空 |
| 评分描述 | 非常差、不太好、还可以、很不错、非常棒等 |
| 评论内容 | UI Tree 中可读取的评论文本 |
| 地区 | `PostInfo` 拆分出的地区 |
| 设备 | `PostInfo` 拆分出的设备型号 |
| 用户 | 固定写为 `匿名用户` |

## 去重键

优先使用以下组合，不使用用户名：

```text
发布时间 + 评分 + 评论内容 + 地区 + 设备
```

## 交付检查

- 日期最小值和最大值落在目标月份。
- 重复行数为 0。
- 记录剩余索引空档数及样例。
- 记录缺失评论内容和缺失评分数。
- 月份文件校验通过后再合并。
- 保留月度 CSV；合并 CSV 不能替代月度原始导出。
