# chart_specs.md

## 统一图表规范

- 图片格式：PNG
- 分辨率：≥150dpi
- 背景：白色
- 字体：微软雅黑、Arial、Noto Sans CJK 或系统默认中文字体
- 标题：中文，包含图号和图意
- 关键数值：必须标注在图元上
- 颜色：使用满意度语义色

## 必备图表

### 图1 周度趋势组合图

- 柱：评论量
- 实线：平均评分
- 虚线：差评率
- 竖虚线：版本事件节点

### 图2 主题热度+满意度横向条形图

- Y 轴：Top 主题
- X 轴：提及数
- 颜色：主题均分语义色
- 标注：N条 · 均分 · 差评率

### 图3 呼声→上线反转图

- X 轴：功能
- 两组柱：上线前均分、上线后均分
- 参考线：全体均分

### 图4 设备满意度图

- Y 轴：设备系列
- X 轴：平均评分
- 标注：均分(n=样本量)
- 参考线：整体均分

### 图5 评分分布图

- X 轴：平台文案 + 星级
- Y 轴：评论数
- 标注：条数 / 占比

### 图6 设备×需求热力图

- 行：功能/诉求
- 列：设备系列
- 单元格：提及占比或加权差评强度
