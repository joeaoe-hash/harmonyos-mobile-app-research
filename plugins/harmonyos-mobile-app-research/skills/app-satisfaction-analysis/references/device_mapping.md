# device_mapping.md

## 映射选择顺序

1. 用户为本次任务明确提供的映射；
2. 同应用、同平台已冻结的项目映射；
3. 与当前平台和品牌一致的内置映射；
4. 无法确认时归为 `其他` 或 `未知`。

把映射名称、版本和 SHA-256 写入 `analysis_quality_check.md`。仅在确认是华为 HarmonyOS 设备时使用下列默认规则；其他品牌或平台不得强套。

## 华为 HarmonyOS 默认设备映射

匹配顺序必须固定：

1. matepad|pad|平板 -> 平板系列
2. matex|mate x|pocket|折叠 -> MateX折叠屏
3. pura|p60|p70|p80 -> Pura系列
4. nova -> nova系列
5. 畅享|enjoy -> 畅享系列
6. mate -> Mate直板机
7. 其他 -> 其他

## 输出字段

- 原始机型
- 设备系列
- 匹配关键词
- 是否低置信度
- 映射名称与版本

## 注意

新机型上市时必须更新项目映射，否则会影响跨期可比性。未知机型不得凭相似名称强行归类；同一分析周期内不得静默修改映射。
